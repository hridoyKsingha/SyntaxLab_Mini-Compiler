# SyntaxLab — Mini Compiler

A Web-Based Mini Programming Language Compiler
Using Flex and Bison.

## Project Description

SyntaxLab is a mini programming language compiler
that analyzes source code and generates
Three Address Code (TAC).

## Technologies Used

- C
- Flex
- Bison
- Python Flask
- HTML
- CSS
- JavaScript

## Main Features

1. Lexical Analysis
2. Syntax Analysis
3. Abstract Syntax Tree (AST)
4. Symbol Table
5. Semantic Analysis
6. Error Detection
7. Three Address Code Generation
